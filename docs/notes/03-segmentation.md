# 3: Basic Vision Models — Segmentation

从像素级预测出发，理解 U-Net、上采样与分割指标，再扩展到三维影像和视频。

## 3.1 分类、检测与分割

| 任务 | 英文 | 输出 |
| --- | --- | --- |
| 分类 | Classification | 整张图像的类别 |
| 检测 | Detection | 目标的边界框与类别 |
| 语义分割 | Semantic segmentation | 每个像素的类别 |
| 实例分割 | Instance segmentation | 每个像素的类别及实例编号 |

[[slide:03:15|四种视觉任务的输出差别]]

语义分割可以把所有细胞都标为“细胞”，实例分割还需要区分哪一些像素属于同一个细胞。分类网络最终输出的向量不再足够；分割需要恢复空间位置。

对 $K$ 类语义分割，输出可写为 $H\times W\times K$ 的分数图。每个位置经过 softmax 得到类别概率，取最大值可得到离散 mask。二分类也可以只输出一个前景 logit 通道。

## 3.2 U-Net：同时需要语义与位置

!!! definition "Encoder–Decoder（编码器—解码器）"
    编码器通过卷积和降采样提取更大范围的上下文；解码器逐渐恢复空间分辨率，将高层特征转换成像素级预测。

U-Net 的两个关键路径：

- **收缩路径**：分辨率降低，通道数通常增加，获得较大感受野。
- **扩张路径**：上采样，与编码器对应分辨率的特征拼接，再细化预测。

[[slide:03:16|原始 U-Net：572 × 572 的输入与 388 × 388 的输出]]

### 为什么原图的输出比输入小？

原始 U-Net 使用不补零的卷积，卷积会缩小空间尺寸。因此输入 $572\times572$，输出为 $388\times388$。它可以用大块上下文预测中央区域，再通过平铺处理更大图像。

现代实现常使用 padding，使输出与输入同尺寸。读论文图与复现代码时应核对具体版本。

### Skip connection（跳跃连接）

[[slide:03:27|U-Net 的 copy and crop：将编码器特征拼接到解码器]]

高层特征提供“是什么”，浅层特征保留“在哪里”。拼接时高、宽必须匹配；原始 U-Net 对编码器特征做 crop，之后沿通道维 concatenate。

!!! example "补充形状例子"
    上采样后特征为 `[B, 128, 64, 64]`，对应的编码器特征也是 `[B, 128, 64, 64]`，沿通道拼接得到 `[B, 256, 64, 64]`。后续卷积的输入通道应设为 256。

## 3.3 上采样与转置卷积

### Transposed convolution

普通卷积在输入上移动卷积核，计算每个输出；转置卷积则可以理解为每个输入值对一片输出位置作贡献，重叠部分求和。

[[slide:03:25|输入加权卷积核，重叠输出相加]]

转置卷积不是对普通卷积求逆。降采样丢失的信息不会因为改变运算方向而自动恢复。

一维尺寸公式为：

$$
W_{\mathrm{out}}=(W_{\mathrm{in}}-1)S-2P+D(K-1)+O+1,
$$

其中 $D$ 为 dilation，$O$ 为 output padding。

!!! note "原图 2 × 2 → 4 × 4 的尺寸约定"
    图中使用 kernel 3、stride 2、padding 1。按 PyTorch 常见约定，若 `output_padding=0`，宽度为 3；要得到图中的 4，可设置 `output_padding=1` 或指定相应输出尺寸。原图没有写全这一实现细节。

### 插值后卷积

另一种做法是先用 nearest / bilinear 等插值放大，再做普通卷积。它与可学习的转置卷积都可以用于解码器。选择时检查输出尺寸、边界处理和棋盘格伪影等现象。

## 3.4 分割指标：IoU 与 Dice

设预测前景集合为 $A$，真实前景为 $B$。

$$
\mathrm{IoU}=\mathrm{Jaccard}(A,B)=\frac{|A\cap B|}{|A\cup B|}
=\frac{TP}{TP+FP+FN}.
$$

$$
\mathrm{Dice}(A,B)=\frac{2|A\cap B|}{|A|+|B|}
=\frac{2TP}{2TP+FP+FN}.
$$

Dice 也称 Dice Similarity Coefficient（DSC）。针对同一对非空集合：

$$
\mathrm{Dice}=\frac{2\mathrm{IoU}}{1+\mathrm{IoU}},\qquad
\mathrm{IoU}=\frac{\mathrm{Dice}}{2-\mathrm{Dice}}.
$$

[[slide:03:33|同一对 mask 的 IoU = 0.25，Dice = 0.4]]

!!! example "把原例算一遍"
    原图中交集与并集之比为 $1/4$。因此 $\mathrm{IoU}=0.25$，代入关系式得到 $\mathrm{Dice}=2\times0.25/(1+0.25)=0.4$。

    Dice 在数值上比 IoU 大，但它们衡量的是同一组重叠关系；不能把两个指标的分数直接横向比较。

Pixel accuracy 容易被背景主导。例如前景占 1%，全预测背景就有 99% 像素准确率，却没有找到任何前景。

多类别分割应报告各类别结果及平均方式。先对每张图算 Dice 再平均，与把所有像素合在一起算 Dice 不是同一种统计；上述换算式也不能随意用于已经平均后的指标。空 mask 的处理规则需要单独约定。

## 3.5 分割损失与二维案例

### 像素级交叉熵与 Soft Dice

可以对每个像素做分类，再汇总交叉熵。若前景很少，可以调整采样或损失权重。

训练时直接对离散 mask 求 Dice 不方便求导，因此使用概率 $p_i$ 与标签 $y_i$ 的 soft 版本。例如：

$$
L_{\mathrm{Dice}}=1-\frac{2\sum_i p_iy_i+\epsilon}{\sum_i p_i+\sum_i y_i+\epsilon}.
$$

不同实现可能使用平方和、不同平滑项或归约方式。代码与论文的定义需要一致，常见组合是交叉熵加 Dice loss。

[[slide:03:38|胸片多结构分割：Dice loss、类别不平衡与分器官评价]]

一种类别加权方法是使用频率的倒数。若频率为 $f_c=n_c/N$，倒数权重应与 $1/f_c$ 成比例；频率本身与倒数不是同一个量。

### FCN 与 DeepLab

FCN 用全卷积方式得到密集输出，再上采样到目标分辨率。DeepLab 使用空洞卷积（atrous / dilated convolution）扩大感受野，并用多个 dilation rate 汇集多尺度上下文。

## 3.6 三维医学图像与 3D CNN

### 通道与空间深度不是一回事

图中给出 $224\times224\times1\times256$ 的 CT 例子：1 是通道数，256 是切片数；视频示例为 $224\times224\times3\times500$，3 是 RGB 通道，500 是时间帧。

[[slide:03:47|CT 与视频尺寸：区分通道、空间和时间]]

PyTorch 的 `Conv3d` 通常使用 `[B, C, D, H, W]`。多序列 MRI 可以放在通道维；相邻切片组成空间深度维。仅把所有切片当作通道交给二维卷积，并不等于三维卷积。

含偏置的普通 3D 卷积参数量为：

$$
(K_dK_hK_wC_{\mathrm{in}}+1)C_{\mathrm{out}}.
$$

三维模型直接利用层间上下文，但特征图占用更多显存。常见处理是提取体积 patch、调整分辨率，或组合二维与三维方法。

### 3D 肺结节分类

[[slide:03:49|3D CNN 原例：从候选结节体积进行分类]]

Huang et al. 的例子先获得候选结节，再让 3D CNN 判断周围体积。它与第 2 章的三个二维视图方案形成对照：一个直接建模体积，另一个先分别提取视图信息再融合。

### 3D U-Net 与稀疏标注

[[slide:03:53|3D U-Net：在少量已标注切片上计算监督损失]]

3D U-Net 把卷积、池化和上采样扩展到三维。标完整体数据成本很高，可以只标一部分二维切片，未标注位置的监督损失权重设为零。

!!! tip "没有标注不等于背景"
    把未标注区域直接填为背景，会向模型提供错误监督。应使用有效标注 mask，把它们从监督损失中排除。

Xenopus kidney 例子（p. 55–57）展示从稀疏标注得到密集预测；p. 58–59 的 PET 脑病灶例子给出两个不同质量的结果。

[[slide:03:59|PET 脑病灶原例：DSC = 0.78 的预测与差异图]]

指标给出一个数，差异图则显示错误在哪里。两者一起看，才容易发现漏分、边界偏移和局部假阳性。

脑微出血的例子属于检测，不应仅因它出现在“分割案例”部分就将其描述成器官 mask 预测。读研究首先要确认任务输出。

[[slide:03:67|肝脏分割原图：3D Deeply Supervised Network]]

### Multi-scale FCN：椎间盘分割

椎间盘（Intervertebral disc，IVD）位于相邻椎体之间，体积小。单一局部纹理可能不足以区分结构，可以通过多尺度三维上下文补充位置信息。

[[slide:03:80|MsFCN：用不同尺度的三维信息定位与分割椎间盘]]

读图时关注各分支看到多大的区域、特征在哪里融合，以及最终输出如何对应目标空间。该研究还在不同时间点的数据上评价定位与分割，以检查时间变化下的稳定性（p. 81）。

### H-DenseUNet：肝脏与肿瘤

CT 体积大、层间上下文重要，而肿瘤在位置、大小、形状和强度上都有变化。H-DenseUNet 将二维与三维信息结合：

1. **粗定位**：先得到肝脏 ROI，减小后续计算范围。
2. **2D DenseUNet**：提取切片内部的层次化特征。
3. **3D 分支**：结合原体数据与二维上下文，建模切片之间的关系。
4. **Hybrid Feature Fusion**：融合二维和三维特征，得到最终预测。

[[slide:03:91|H-DenseUNet：二维分支、三维分支和 Hybrid Feature Fusion]]

[[slide:03:98|H-DenseUNet 的组件比较：判断各部分是否带来收益]]

LiTS 数据具有不同的切片间距，比较时还需核对训练与测试体积（p. 95）。p. 96–108 的比较应结合肝脏与肿瘤的不同指标阅读，不能只挑单个最佳数值。

!!! note "Dense connection 与 U-Net connection"
    DenseNet 式连接加强块内特征流动与复用；U-Net 式连接把编码器的局部信息送到解码器。混合模型中二者可以同时存在，不能仅凭名称把它们混为一种操作。

## 3.8 视频：把时间关系加入模型

医学视频包括超声心动图、手术视频和 ICU 活动视频。时间维度的顺序有意义，单帧分类可能丢失运动和过程信息。

### I3D 与 Optical Flow

I3D 将 Inception 的二维结构扩展为三维卷积，第三个滑动维度是时间。初始化时可把二维预训练权重沿新增维度复制并归一化，迁移到三维网络。

[[slide:03:116|I3D：时空卷积与二维预训练权重的扩展]]

光流（optical flow）估计相邻帧的位移，常表示为水平、垂直两个分量。RGB 描述外观，光流提供运动线索；two-stream 模型分别处理它们，再融合。

[[slide:03:125|CNN + LSTM、3D CNN 与多种双流方案]]

### CNN + RNN / LSTM

CNN 先提取每一帧特征 $v_t$，循环模型再处理特征序列。普通 RNN 可以写为：

$$
h_t=\tanh(W_{hh}h_{t-1}+W_{vh}v_t+b_h),\qquad
z_t=W_{hy}h_t+b_y.
$$

[[slide:03:128|CNN + RNN 按时间展开：每帧特征与隐藏状态]]

不同时间步共享参数。LSTM 是带门控和记忆状态的循环网络。联合训练 CNN 和 RNN 参数较多，也可以先训练或微调单帧 CNN，再提取特征训练序列模型。

## 3.9 自测

??? question "为什么语义分割只用编码器通常不够？"
    编码器降低了空间分辨率，适合获取语义，但像素级输出还需要定位。解码器、上采样及跳跃连接帮助恢复和利用空间细节。

??? question "IoU = 0.5 时，Dice 是多少？"
    对同一对 mask，$D=2J/(1+J)=1/1.5=2/3$。注意这不是对平均指标普遍成立的换算。

??? question "为何不把所有三维医学任务都直接交给最大的 3D 网络？"
    三维网络显存与计算开销高，训练数据和标注也可能不足。二维、三视图、patch 与混合方法都在信息利用和资源约束之间作选择。
