# 4: Training Strategies & Retinal Images

连接数据预处理、增强和损失函数，认识眼底与 OCT，并分析视网膜影像研究。

## 4.1 Data Preprocessing（数据预处理）

### 零均值、标准化与白化

输入的数值尺度影响优化。把不同量纲或动态范围直接放在一起，可能使损失对某些参数方向尤其敏感。

$$
x'=\frac{x-\mu}{\sigma+\epsilon}.
$$

减去均值称为 zero-centering；再除以标准差得到标准化后的值。$\epsilon$ 用于避免分母为零。

[[slide:04:17|原始数据、零中心化与标准化]]

PCA 去相关与 whitening（白化）是另外两种处理：前者通过坐标变换得到对角协方差，后者进一步调整尺度，使协方差接近单位矩阵。图像 CNN 中更常见的是按通道减均值、除标准差，而不是直接进行 PCA 白化。

| 操作 | 统计量的形状或含义 | 示例 |
| --- | --- | --- |
| 减均值图像 | 每个位置一个均值 | AlexNet |
| 减通道均值 | 每个通道一个均值 | VGG |
| 通道标准化 | 每通道均值与标准差 | ResNet |

全数据集的归一化统计量应从训练集估计，并固定用于验证和测试。逐病例强度标准化则可以在单个输入内计算，关键是明确且固定预处理协议。

### 医学影像的四个常见处理

**Patching**：把大图像或体数据划分为小块。patch 越小，显存压力越低，但上下文也越少。

[[slide:04:22|3D patch 训练与有重叠的滑窗推理]]

原例使用 $96\times96\times96$ patch，训练时不重叠，推理时采用 50% 区域重叠。这是所举方法的设置，不是所有 3D U-Net 的固定要求。滑窗推理需要融合重叠区域的预测，避免明显的拼接边界。

**Oversampling**：增加少数类或前景区域被抽中的机会。一种策略是：70% 随机位置，30% 保证包含至少一种前景。

[[slide:04:23|随机采样与前景采样的组合]]

这改变的是训练采样分布，不代表应该把验证、测试集也人为平衡。后者应体现目标评价人群。

**Resampling**：统一像素/体素对应的物理尺度。$1\times1\times5$ mm 与 $1\times1\times1$ mm 的体数据，即使数组大小一致，解剖结构的尺度也不同。

**Intensity normalization**：处理强度范围，例如 z-score 标准化。具体策略与模态有关，CT 的物理强度和 MRI 的相对强度不能一概而论。

!!! tip "图像与标签要一起处理"
    重采样、裁剪、旋转必须保持图像与 mask 对齐。补充实现建议：离散标签通常使用最近邻插值，避免插值出不存在的类别编号；记录 spacing、方向和坐标变换，以便将预测恢复到原空间。

## 4.2 Data Augmentation（数据增强）

增强可以分为传统变换（GTAug）与基于 GAN 的生成式方法（GANAug）。传统变换既包括几何操作，也包括亮度、对比度、噪声等外观扰动。

| 类型 | 例子 | 医学任务中的检查点 |
| --- | --- | --- |
| 几何变换 | 翻转、旋转、平移、缩放、裁剪 | 解剖侧别与标签是否仍成立 |
| 强度变换 | brightness、contrast、gamma | 是否仍类似真实采集变化 |
| 质量扰动 | 模糊、噪声、低分辨率模拟 | 是否把小病灶破坏到不可辨认 |
| 图像混合 | mixup、CutMix | 标签如何同步组合，是否适合当前任务 |
| 生成式增强 | GAN 生成或转换图像 | 合成样本是否保持病理特征及标签一致性 |

[[slide:04:27|2D / 3D U-Net 数据增强方式]]

2D 分割中的随机几何变换应同步作用于图像与标签。3D 数据要保持体积内部的一致性，不能随意对每张切片施加互相独立的几何变换。

[[slide:04:28|GAN-based augmentation：利用生成模型增加样本变化]]

增强主要作用于训练集；它增加变化，却不等于增加独立病例。验证与测试预处理应保持可重复，使用 test-time augmentation 时也要明确报告。

## 4.3 Loss Functions（损失函数）

### 交叉熵的数值例子

[[slide:04:33|softmax 概率与交叉熵的计算]]

原图的 softmax 输出为 `[0.7751, 0.1159, 0.0386, 0.0703]`，标签为 `[1, 0, 0, 0]`。采用自然对数：

$$
L=-\sum_k y_k\log p_k=-\log(0.7751)\approx0.2548.
$$

原图显示约 0.2547，与概率展示精度有关。one-hot 标签中只有正确类别的项保留下来，因此交叉熵鼓励该类别的概率变大。

!!! tip "交叉熵的接口约定"
    在 PyTorch 中，`CrossEntropyLoss(logits, target)` 内部包含 log-softmax。这里的手算先展示概率，是为了解释数学含义，不意味着代码中要先对输入做 softmax。

### 回归损失与 Contrastive Learning

LVEF 是连续数值，直接用 MSE 可以要求预测接近目标。进一步可以问：是否还能约束**特征空间**，让标签接近的样本表示也更接近？

[[slide:04:31|LVEF 原例：从输出上的 MSE 到特征空间上的对比约束]]

分类中的对比学习常按类别区分正负样本。但回归标签有连续距离：LVEF 相差 1 与相差 30 不应被同等看待。AdaCon（Adaptive Contrast）针对回归标签关系构造自适应约束。

[[slide:04:35|分类标签与连续回归标签的结构]]

阅读这种方法时分清两个作用：回归项让输出数值正确，对比项组织中间特征的相对关系。附加损失的权重同样需要通过验证集选择。

## 4.5 眼部生理与常见疾病

### 眼球的主要结构

[[slide:04:44|眼部结构：角膜、虹膜、瞳孔、巩膜与视神经]]

| 结构 | 英文 | 作用或位置 |
| --- | --- | --- |
| 角膜 | Cornea | 位于眼前部，透光并参与折射 |
| 虹膜、瞳孔 | Iris / Pupil | 调节进入眼内的光量 |
| 晶状体 | Lens | 参与将光线聚焦到视网膜 |
| 视网膜 | Retina | 眼球内侧感光组织，将光信号转为神经信号 |
| 黄斑、中央凹 | Macula / Fovea | 与精细中央视觉密切相关 |
| 视盘、视神经 | Optic disc / Optic nerve | 神经纤维汇聚并传递视觉信息 |
| 脉络膜 | Choroid | 位于视网膜外侧的重要血管组织 |

用相机作类比，视网膜类似感光底片。光学成像和后续神经处理是不同过程，模型看到的图像还取决于采集设备。

### 常见眼病

| 疾病 | 英文 | 基本变化 |
| --- | --- | --- |
| 近视 | Myopia | 未矫正时远处物体的光线聚焦在视网膜前 |
| 糖尿病视网膜病变 | Diabetic retinopathy | 与糖尿病相关的视网膜血管损伤 |
| 青光眼 | Glaucoma | 视神经损伤；眼压升高是重要风险因素，但并非所有病例都高眼压 |
| 年龄相关性黄斑变性 | Age-related macular degeneration, AMD | 黄斑受损，影响中央视觉 |
| 白内障 | Cataract | 晶状体混浊，影响透光与视觉 |

这里的目的，是把图像中可见的结构与研究任务联系起来。比如 DR 分级依赖眼底病变，而 OCT 可以进一步观察积液及视网膜层次。

## 4.6 Fundus 与 OCT：不同成像提供什么信息？

### 眼底照片与断层结构

眼底照片提供视网膜表面的整体视图；OCT（Optical Coherence Tomography）提供沿深度方向的断层信息。

[[slide:04:57|同一眼底区域的表面视图与 OCT 横断面]]

读这张图时，先在眼底照片中定位扫描线，再看对应 OCT 横断面的层状结构。二维照片里相互叠加的变化，在 OCT 中可以按深度区分。

### 自发荧光、红外与 OCTA

红外、自发荧光与彩色照片提供不同的观察方式。它们对不同组织和信号敏感，不能理解成仅仅更换配色。

- **Fundus autofluorescence（FAF）**：体现内源性荧光相关信号的分布，提供与色素上皮等组织状态有关的信息。
- **Infrared imaging**：提供不同波段下的组织对比。
- **OCT angiography（OCTA）**：借助重复扫描的运动信号观察血流相关结构，无需注射染料。

### 保留病例：AMD 与治疗反应

[[slide:04:62|AMD 原例：表面病灶与 OCT 中的组织层次]]

眼底可以看到萎缩、出血等表面表现，OCT 帮助确定改变处于哪一层，以及是否存在组织变薄或积液。

[[slide:04:65|治疗随访原例：OCT 中液体随时间变化]]

图中不同时间点的 OCT 对比展示积液变化。对 AI 而言，这可以进一步形成分类、分割、液体定量或进展预测任务；任务定义要说明比较的是当前状态还是未来变化。

[[slide:04:68|脉络膜原例：先分割结构，再进行定量分析]]

这一页把第 3 章的分割与眼科应用连接起来：mask 不是终点，它还可以用于厚度、面积等结构测量。定量时应考虑像素尺度与扫描协议。

## 4.7 RETFound：视网膜基础模型

研究题目：*A foundation model for generalizable disease detection from retinal images*（来源：p. 71–79）。

**问题**：为每一种眼病单独收集大量标签并训练模型，成本很高。是否可以先从无标签影像学习可迁移的表示？

**方法**：使用 Masked Autoencoder（MAE）进行自监督预训练，遮挡部分图像块，要求模型重建；再为下游任务适配表示。

[[slide:04:73|RETFound：通过重建被遮挡图像块学习表示]]

研究中的下游任务包括眼病诊断、眼病预后和系统性疾病风险预测。它们的标签与时间含义不同，不能仅因为共享特征就混为同一个任务。

| 观察方向 | 需要回答的问题 |
| --- | --- |
| 跨数据集诊断（p. 74） | 训练与测试人群改变后，表现如何？ |
| 预后与系统性疾病（p. 75–76） | 是否包含未来时间信息，如何定义事件？ |
| 标签效率（p. 77） | 相同标签量下，与哪些方法比较？ |
| 年龄分布变化（p. 78） | 不同年龄组之间是否稳定？ |
| 关注区域（p. 79） | 模型响应区域与病灶是否相关？ |

[[slide:04:77|RETFound 的标签效率实验：不同标注量下的表现]]

这些是该研究中的实验观察，结论适用于对应数据和对照方法；关注图也不自动构成因果解释。

## 4.8 其余四组研究案例

### DeepDR Plus：预测多久之后发生进展

研究题目：*A deep learning system for predicting time to progression of diabetic retinopathy*（p. 80–88）。

普通分级回答“现在是什么状态”，time-to-progression 预测回答“未来何时可能进展”。后者需要纵向随访和时间到事件建模。

[[slide:04:82|DeepDR Plus：特征预训练、进展建模与 Weibull 时间模型]]

该方法结合自监督特征学习、进展模式学习和 Weibull 模型，并通过风险分层、Kaplan–Meier 曲线及实际管理研究评价。读 Kaplan–Meier 图时关注事件定义、随访时间、删失和组间差异，不能把曲线间距直接当作普通分类准确率。

[[slide:04:85|DeepDR Plus 的风险分层：不同组的时间到事件曲线]]

### DeepDR-LLM：图像模型与语言模型协作

研究题目：*Integrated image-based deep learning and language models for primary diabetes care*（p. 89–97）。

影像模块提供质量评估、病灶分割、DR / DME 分级等结果；语言模块结合这些结果和其他输入生成个体化管理建议。两类模型承担不同角色。

[[slide:04:90|DeepDR-LLM：语言模块与眼底影像模块的连接]]

该研究还探索从标准眼底照片迁移到便携设备照片，以及输出适当性、医生辅助实验和实际应用评价。分析时分开看影像识别准确性、文本质量和工作流程效果，不能由某一个模块的分数推断整体系统效果。

### 智能手机儿童视力筛查

研究题目：*Early detection of visual impairment in young children using a smartphone-based deep learning system*（p. 98–106）。

这里的输入是按引导采集的儿童视频，利用外观和视觉行为线索筛查风险，并非手机直接获取 OCT。

[[slide:04:99|手机筛查原例：环境选择、手机固定与引导式视频采集]]

该研究的开发数据涉及 2,344 名儿童，验证组 305 名，另有 125 名远程志愿者。它进一步比较不同年龄、性别和拍摄环境，并分析可能相关的行为特征。

[[slide:04:105|儿童视力筛查：观察模型使用的行为线索]]

学习重点是**数据采集协议本身就是系统设计的一部分**。模糊、遮挡、视线和拍摄环境改变，可能同时影响输入质量与模型表现。

### SLIViT：二维表示用于三维扫描

研究题目：*Accurate prediction of disease-risk factors from volumetric medical scans by a deep vision model pre-trained with 2D scans*（p. 107–112）。

逐切片使用二维特征提取器，再以 Transformer 聚合切片特征，获得体积级预测。其训练包括 ImageNet 初始化与三维 OCT 数据上的后续预训练。

[[slide:04:108|SLIViT：二维切片特征提取与体积特征聚合]]

研究在 OCT、超声、MRI、CT 等数据上比较表现及预训练方案。它与第 3 章混合模型的共同问题是：如何利用可获得的二维表示，同时保留三维上下文。

## 4.9 自测

??? question "把 CT 数组 resize 成同样大小，是否等于统一了物理尺度？"
    不一定。还要使用原始 spacing 和方向信息。相同像素数量可以代表不同的实际长度。

??? question "为什么回归对比学习不能简单套用“同类为正、异类为负”？"
    连续标签之间存在距离和顺序，简单二分会丢掉这些关系。回归对比方法需要根据连续目标设计相似性或约束。

??? question "眼底照片与 OCT 为什么可以互补？"
    眼底照片提供整体表面视图，OCT 提供断层深度结构。相同病变在两种成像中可能体现为不同但相关的信息。

??? question "阅读研究结果表，先核对哪四件事？"
    任务与标签定义、训练/测试人群、对照方法、评价指标及协议。随后再解释模型是否在这些条件下带来改进。
