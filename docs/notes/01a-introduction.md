## 1a.1 为什么学习医学影像分析？

医学影像是疾病筛查、诊断、治疗规划和随访的重要信息来源。同样是“让模型看图”，不同任务需要的输出并不相同：判断是否患病是分类，勾画器官边界是分割，预测骨密度是回归。

课件先展示了多种成像方式。需要注意：**图像的颜色、维度和强度含义由成像机制决定**，不能把所有医学图像都当作普通 RGB 照片处理。

[[slide:01a:6|二维医学影像：X-ray、眼底、皮肤镜和组织病理]]

| 类型 | 英文 | 数据特点与典型用途 |
| --- | --- | --- |
| X 射线影像 | X-ray | 投影成像；常见于胸片、骨骼检查 |
| 眼底照片 | Fundus photography | 观察视盘、血管、黄斑及病灶 |
| 皮肤镜影像 | Dermoscopy | 皮肤表面病变的局部细节 |
| 组织病理影像 | Histopathology | 显微组织结构；整张切片往往很大 |
| 计算机断层成像 | CT | 多张切片构成体数据，包含三维空间信息 |
| 磁共振成像 | MRI | 不同序列突出不同组织信息，可形成多模态输入 |
| 光学相干断层成像 | OCT | 显示组织的深度结构，眼科中常用于视网膜层次观察 |

[[slide:01a:7|CT、MRI 与 OCT：从二维图片走向体数据]]

!!! tip "重点：先问数据是什么"
    一张眼底照片与一个 CT 体积不是同一种输入。网络设计前，先确认空间维度、通道、像素或体素间距，以及预测目标。第 3 章会进一步区分二维卷积与三维卷积。

## 1a.2 Artificial Intelligence / Machine Learning / Deep Learning

!!! definition "三个概念的关系"
    **Artificial Intelligence（AI，人工智能）**：让计算机完成通常需要智能的任务。

    **Machine Learning（ML，机器学习）**：从数据中学习规律，是 AI 的一类方法。

    **Deep Learning（DL，深度学习）**：使用多层模型学习表示，是 ML 的一类方法。

三者是包含关系。不是所有 AI 都需要神经网络，也不是所有机器学习都是深度学习。

传统图像学习流程通常是：

> 输入图像 → 人工设计特征 → 分类器或回归器 → 输出

深度学习把特征提取也放入可训练模型中：

> 输入图像 → 逐层学习特征 → 任务输出

[[slide:01a:30|从手工特征到直接学习层次化表示]]

### 人工智能的发展线索

课件 p. 9–24 按时间介绍了早期感知机、AI 发展的低谷、现代神经网络、2012 年图像分类突破、ResNet、Transformer、ViT 和生成模型。这里主要关注三个条件：**数据、计算能力和模型方法共同推动了深度学习的发展**。

| 阶段 | 课件中的代表内容 | 学习时关注的问题 |
| --- | --- | --- |
| 1950–1960 年代 | 感知机与早期 AI | 简单模型的表达能力有哪些限制？ |
| 1980–2000 年代 | 神经网络重新发展、LSTM | 多层模型与序列模型如何训练？ |
| 2012 年 | AlexNet / ImageNet | 大数据和 GPU 如何改变图像识别？ |
| 2015 年 | ResNet | 更深的网络如何优化？ |
| 2018–2021 年 | BERT、Vision Transformer | 表示学习与预训练如何迁移？ |
| 后续发展 | 图像、视频生成与机器人 | 学到的表示还能支持哪些任务？ |

## 1a.3 从分类例子理解“学习”

### 苹果与猫头鹰

训练阶段提供带标签的图片，让模型调整参数；预测阶段输入新图像，模型给出各类别的分数或概率。

[[slide:01a:28|课件例子：Apple / Barn owl 的训练与预测]]

图中的输出 `[0.34, 0.66]` 与 `[0.98, 0.02]` 表示对两个类别的不同判断。读这样的向量时，必须先知道**类别顺序**。如果第一维对应 Apple，第二维对应 Barn owl，那么最大值的位置才可以转换成类别名称。

!!! note "分类、回归与分割"
    分类输出离散类别；回归输出连续数值；分割为每个像素或体素输出类别。相同的图像可以支持多个任务，任务不同，最后一层和损失函数也会变化。

### 模型学到了什么？

浅层特征常反映边缘、颜色和纹理；更深的层可以组合局部结构，形成与任务相关的抽象表示。课件用“边缘 → 局部部件 → 完整对象”说明层次化特征。

[[slide:01a:33|低层、中层与高层特征的可视化]]

这种可视化帮助建立直觉，但不能把每个神经元都固定解释成某个医学概念。医学图像中的有效特征需要结合任务和实验验证。

## 1a.4 Convolutional Neural Network（CNN）

全连接层（Fully connected layer）把每个输入连接到每个输出。图像一旦展平，参数很多，而且空间邻接关系不再由结构直接体现。

卷积层（Convolutional layer）用小卷积核在图像上滑动。相同卷积核在不同位置共享参数，既利用局部结构，也减少参数量。

| 组成 | 主要作用 | 需要区分的概念 |
| --- | --- | --- |
| Convolution | 提取局部特征 | 卷积核参数是训练得到的 |
| Activation | 引入非线性 | 多层纯线性变换仍是线性变换 |
| Pooling | 汇聚、降低空间分辨率 | 常见最大池化本身没有可学习参数 |
| Fully connected | 综合特征并产生输出 | 不是所有现代 CNN 都必须使用大规模全连接层 |

[[slide:01a:40|课件中的简单图像分类 CNN]]

读网络图时，从左向右记录每一层的输入形状、输出形状和作用。卷积后的“深度”通常指通道数，不一定是医学体数据的空间深度。

### AlexNet

AlexNet 是课件用于说明 2012 年突破的例子。它结合卷积、池化和全连接层，把学习到的图像表示用于大规模分类。具体层数和输出尺寸在第 2 章继续展开。

## 1a.5 网络怎样训练？

训练由一个循环构成：

1. **Forward pass（前向传播）**：输入图像，得到预测。
2. **Loss（损失）**：比较预测与标签，量化差异。
3. **Backpropagation（反向传播）**：计算损失对参数的梯度。
4. **Update（更新）**：优化器根据梯度改变参数。

[[slide:01a:44|课件例子：dog / cat / horse 的预测逐渐接近标签]]

图中类别顺序为 dog、cat、horse，真实标签写成 one-hot 向量 `[1, 0, 0]`。随着训练，dog 对应的输出从很小变大，预测逐渐与标签一致。

!!! tip "读图时的注意点"
    原图中的 error 是教学示意，没有完整说明计算约定。不要直接用它反推某一种损失公式。第 1b 章会明确定义 MSE，第 2 章会定义交叉熵。

## 1a.7 自测

??? question "一张 CT 切片与一个 CT 体积，模型输入有什么区别？"
    切片通常只有两个空间维度；体积还包含层间空间维度。体数据的层间间距不一定与平面内分辨率一致，因此输入尺寸相同也不意味着物理尺度相同。

??? question "为什么卷积层可以比全连接层使用更少的参数？"
    因为卷积使用局部连接，并在不同空间位置共享卷积核参数。参数量主要由卷积核大小、输入通道数和输出通道数决定。

??? question "训练时梯度是什么，预测时还需要它吗？"
    梯度描述损失对参数的局部变化率，用于更新参数。普通预测只需前向传播；做归因分析等特殊任务时才可能另外计算梯度。
