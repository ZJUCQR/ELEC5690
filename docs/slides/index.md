## 使用说明

- 选择页码或使用左右方向键翻页；链接中的 `#page=33` 表示定位到第 33 页。
- 点击图片放大，按 `Esc` 关闭。选择“原始尺寸”可以仔细查看小字与网络结构。
- 每份课件下方有按 20 页分组的静态图集，可连续阅读全部原页。
- 图片是原始 PDF 的逐页呈现，原有公式、例子、图注和署名均保留。原 PPT 中的动画只能体现为 PDF 已有的页面序列，外链视频仍需访问原来源。

!!! info "原图与文字"
    部分课件把正文嵌在图片中。笔记对这些页面另行整理，但阅读论文细节、实验表格和数值时，仍建议结合原图。各章开头均有原 PDF 和逐页浏览入口。
